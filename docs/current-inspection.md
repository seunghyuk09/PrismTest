# 현행 검사 방식 분석 (사내 자료 3건 기반)

출처: `Plastic Prim 불량 검사`, `플라스틱 프리즘 검사`, `U20-AP 프리즘 검사 흐름도`

## 대상물
- 품번 **U20-AP**, **플라스틱 사출 프리즘**
- 검사 단계에서는 투명. **페인트는 WK 공정에서 조립 직전에 도포**
  (참고 사진이 흑색 도장 상태였던 이유)
- 재질 상세(PMMA/PC), 치수는 여전히 미확정

## 현행 검사 지그 = LED 패널 + 삼각대 + 맨손

| 항목 | 내용 |
|---|---|
| 광원 | **Ulanzi VL49** LED 패널, CRI 95+, 내장배터리 2000mAh, 조광 가능 |
| 거치 | 미니 삼각대에 LED만 고정 |
| 시료 | **작업자가 손으로 들고** LED 앞/옆에 위치 |
| 관찰 | 눈으로 비스듬한 각도에서. "관찰 각도를 근사하게 맞추면 내부 확인 가능" |
| 설정 | 밝기 **최대** |
| 절차 | 반대면은 프리즘을 뒤집어 재검사 |
| 배경 | 흰색 격자 종이 / 흰 벽 |

### 평가
**광학 원리는 이미 옳다.** 측면 그레이징 조명 + 비축 관찰은 사실상 암시야다.
검사원이 경험으로 올바른 방향을 찾아냈으므로 조명 방식을 새로 발명할 필요가 없다.

**문제는 재현성과 배경 두 가지다.**

1. **배경이 밝다** — 암시야는 배경이 검을 때 완성된다. 흰 배경은 투과광이 섞여
   결함 대비(ΔI/I)를 직접 깎는다. **검은 무광 배경만 추가해도 즉시 개선된다.**
2. **손으로 들고 있다** — 각도·거리 재현성이 없다.
   "결함이 안 보인다"가 아니라 "각도를 못 찾았다"인 경우가 섞여 있을 것이며,
   검사원 간 판정 편차의 주된 원인일 가능성이 높다.

### 앱용 지그 설계 방침
현행 세팅을 버리지 말고 **세 가지만 추가**한다.
1. 검은 무광 배경 (프리즘 뒤/아래)
2. 프리즘 안착부(nest) — 검사원이 "잘 보인다"고 하는 각도로 고정
3. 폰 거치대 — 지금 "눈"이 있는 위치에 카메라를 고정

→ 검사원이 이미 검증한 광학 조건을 그대로 재현하면서 재현성만 확보한다.

### 광원 관리 주의
- VL49는 **내장 배터리 구동**이다. 잔량에 따라 광량이 떨어지고 지수가 통째로 흐른다.
  → **USB-C 상시 급전** 권장. 앱은 화이트 기준 패치로 광량 드리프트를 감시한다.
- 밝기 "최대"는 좋은 선택이다. LED 조광은 PWM이라 중간 밝기에서 롤링셔터 밴딩이
  생길 수 있는데, 최대에서는 duty 100%라 그 문제가 없다. **밝기 최대를 규격으로 고정한다.**

## 불량 유형 — 기준서 7종

| No. | 유형 | 검사 방법 | 검사처 |
|---|---|---|---|
| 1 | **표면 불량** | 지그 검사 | OPL / SG / WK |
| 2 | 내부 가스 (내부에 흰색 구름띠 형성) | 지그 검사 | 〃 |
| 3 | 표면 찍힘 (**동일위치**) | 지그 검사 | 〃 |
| 4 | 먼지 (흰색, 검정색) | 지그 검사 | 〃 |
| 5 | 스크래치 (**동일위치**) | 지그 검사 | 〃 |
| 6 | 버 (Burr) | **손끝으로 만져서** 검사 | OPL |
| 7 | 게이트 절단 불량 | 육안 검사 | OPL |

비고: "크기가 작아 검사에서 걸러지지 않는 경우 페인트 후 영상검사에서 불량 판별"

### 읽어낸 것
- **"표면 불량"은 얼룩이 아니라 성형 불량이다.** 첨부 사진의 뿌연 구름 + 미세 과립
  텍스처는 세정 잔사가 아니라 사출 유래(플로우마크/실버스트릭/가스 자국/금형 전사)다.
  닦아도 지워지지 않는 이유가 여기 있다. 명칭이 오해를 부르고 있다.
  검출 관점에서는 오히려 유리하다 — 광택 차이와 미세 산란이 커서 암시야에서 잘 뜬다.
- **"동일위치"** = 금형 유래. 결함이 항상 같은 위치에 나온다면 **ROI를 좁혀 집중 검사**할 수
  있고 위치 정보를 판정 특징으로 쓸 수 있다. 알고리즘에 유리한 조건이다.
- 6번(버)은 촉각 검사라 **카메라로 대체 불가**. 앱 적용 범위에서 제외하고 명시한다.
- 7번(게이트 절단)은 특정 부위 형상 문제라 별도 ROI로 다룰 수 있다.

## 용어 불일치 — 확인 필요

| 검사기준서 (7종) | 파레토 표 (11종, n=15,120) |
|---|---|
| 표면 불량 | 표면 얼룩 5,843 (38.64%) |
| **내부 가스 (흰색 구름띠)** | **내부 백태 0건** |
| 표면 찍힘 (동일위치) | — |
| 먼지 (흰색/검정색) | 흰색 이물 512 / 검정색 이물 118 |
| 스크래치 (동일위치) | 스크래치 244 |
| 버 (Burr) | — |
| 게이트 절단 불량 | — |
| — | Diffuser 얼룩 / Dig / 파손 / 내부 기포 / 페인트 얼룩 |

**기준서의 정식 항목인 "내부 가스"가 파레토에서 0건이다.**
실제로 발생하지 않는 것이 아니라 "표면 얼룩"으로 흡수되고 있을 가능성이 높다.
표면 불량 38.64%라는 수치의 신뢰성이 여기에 걸려 있다.

→ 한도 테스트 시 **표면 불량 / 내부 가스를 반드시 분리 기록**한다.
   구분 수단: **시차(parallax) 테스트** — 관찰 위치를 좌우로 옮겼을 때
   결함이 표면 기준으로 이동하면 내부 가스, 안 움직이면 표면 불량.
   (플라스틱이라 재세정 검증은 불가 — 닦으면 스크래치가 생긴다)

## 공정 흐름 (U20-AP)

```
OPL  생산 → 생산검사(육안·지그) → 포장(생산일자·일련번호) → 납품
              └ 불량 → 폐기 및 금형 수선          ← 재작업 없음
SG   입고 샘플검사(육안·지그) → 입고처리 → 생산투입
              └ 불량 → 전수검사(육안·지그)
                        ├ 단품/소량 불량 → 입고처리
                        └ 대량 불량(금형) → OPL 반품·협의
WK   전수검사(육안·지그) → 페인트 → 조립검사(영상) → 생산완료 → 납품
```

입고 샘플링: **박스당 1 tray = 42 EA**, 입고 후 2주 내 완료.

### 함의
- **같은 물건을 최소 3회 육안검사**(OPL·SG·WK)한다. 앱의 투자 대비 효과가 크다.
- 그러나 **세 공정의 판정 기준이 동일한지 확인이 필요하다.** 앱을 어느 기준에
  맞출 것인지 먼저 정해야 한다. 파레토 15,120건이 어느 단계 데이터인지도 확인 대상.
- **불량은 폐기 확정**(재작업 경로 없음) → **과검 1건 = 폐기 1건**.
  임계값 결정 시 이 비용 구조를 반영한다.
- 트레이 단위(42 EA)가 존재하므로 택트타임 목표는 트레이 기준으로 환산 가능.

## 이 문서로 해소된 것 / 남은 것

**해소**
- 재질(플라스틱 사출), 품번(U20-AP), 페인트 시점(WK 조립 직전)
- 현행 조명 방식과 광원 사양, 결함 유형 정의, 공정 흐름, 폐기 정책

- 검사원 간 판정 일치도 (오늘 한도 테스트에서 측정)
