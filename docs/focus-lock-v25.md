# v25 초점 고정 수정

v24는 고정할 때 자동초점을 끄고, 직전 카메라가 보고한 초점 거리를 수동 명령으로 다시 보냈다. 거리 값이 없으면 기본값 4 D로 대체했다. 자동 상태와 고정 상태 사이에 샤프닝·노이즈 처리도 달라졌다. 기기에 따라 고정 순간에 초점 위치나 보이는 질감이 달라질 수 있는 경로였다.

v25는 검사 영역 중심에 자동초점을 맞추고, 카메라의 자동초점 잠금을 유지한다. 일반 고정 동작은 수동 초점 거리 명령을 보내지 않는다. 실제 촬영 결과의 성공한 AF 잠금 상태와 렌즈 정지를 확인한 다음 노출·화이트밸런스를 고정한다. 검사 중 자동 잠금 해제 타이머를 사용하지 않는다.

## 사용 방법

1. 프리즘 모서리나 결함처럼 경계가 보이는 부분을 검사 영역 중앙에 놓는다. 화면을 누르면 영역 중심을 옮길 수 있다.
2. **초점 맞춰 고정**을 누르고 폰과 프리즘을 잠깐 멈춘다.
3. **초점 잠금 확인됨 / 촬영 조건 고정됨**이 보이면 검사한다. 같은 거리를 유지하며 프리즘을 돌린다.
4. 흐리거나 검사 거리가 달라졌으면 **초점 다시 맞춤**을 누른다. 실패하면 거리를 조금 늘리거나 모서리를 조준해 다시 시도한다. 투명한 면 중앙만 조준하면 뒤쪽 배경에 초점이 잡힐 수 있다.

검색·실패·렌즈 이동 중에는 검사 시작을 허용하지 않는다. 잠금 중 **취소**를 누를 수 있고, **자동**으로 돌아가면 잠금을 푼다. 화질·카메라 화면 크기·배율을 바꾸면 기존 잠금을 재사용하지 않고 다시 맞추도록 한다. 카메라가 잠금을 잃으면 검사 시작이 대기 상태가 된다.

프리뷰가 준비되기 전에는 고정 버튼을 활성화하지 않는다. 실패 이유는 고정 버튼 아래에 표시한다. 최소 초점 거리가 명시적으로 0 D인 고정초점 렌즈는 자동초점 검색 대신 AF OFF 상태를 확인하고 **고정 초점 렌즈 확인됨**을 표시한다. 최소 거리 정보가 없다는 이유만으로 고정초점 렌즈로 취급하지 않는다.

수동 초점은 설정의 슬라이더를 직접 조작할 때만 적용한다. 기기에 따라 거리 단위의 정확성이 달라 D(diopter)로 표시하며, 숫자를 실제 피사체 거리로 단정하지 않는다. 고정초점 카메라에는 지원하지 않는 수동 조절을 제공하지 않는다.

초점 거리 보고가 없어도 성공한 하드웨어 잠금은 사용할 수 있다. 다만 다른 잠금 세션의 초점이 같다고 확인할 수 없으므로 이전 검사 기준을 재사용하지 않는다. 무한대를 뜻하는 실제 0 D 값과 보고 없음은 구분한다. 자동초점 잠금·수동 초점 방식이 바뀐 기존 기준도 새 조건에서 다시 등록해야 한다. 사진과 기존 기록은 보존한다.

샤프닝·노이즈 처리 요청은 자동 상태와 고정 상태에서 같게 유지한다. 저장 사진과 실시간 판정 모두 이 카메라 스트림을 사용하며, 컬러 PNG 저장과 HD/FHD/QHD/4K 화질 선택을 유지한다.

## 검증 범위

단위 테스트로 성공·실패·검색·렌즈 이동 상태, 미보고·무한대 초점 거리, 수동 초점의 실제 적용, 초점 방식별 기준 분리를 확인한다. Android 실행 테스트는 실제 CameraX 스트림에서 잠금, 기본 자동 해제 시간 이후 유지, 해제·재고정, 화질 변경 후 재고정을 확인한다. 가상 카메라 테스트는 실제 폰 렌즈의 선명도를 측정하지 않는다.
