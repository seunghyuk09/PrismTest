# v25 초점 고정 수정

v24는 고정할 때 자동초점을 끄고, 직전 카메라가 보고한 초점 거리를 수동 명령으로 다시 보냈다. 거리 값이 없으면 기본값 4 D로 대체했다. 자동 상태와 고정 상태 사이에 샤프닝·노이즈 처리도 달라졌다. 기기에 따라 고정 순간에 초점 위치나 보이는 질감이 달라질 수 있는 경로였다.

v25의 **현재 초점 고정**은 연속 자동초점이 맞은 상태에서 카메라의 잠금 명령을 사용해 현재 위치를 유지한다. 성공한 잠금과 렌즈 정지를 실제 촬영 결과에서 확인한 다음 노출·화이트밸런스를 고정한다. 수동 초점 거리 값을 다시 보내지 않는다. 새 초점 검색은 **초점 다시 맞춤**으로 요청한다. 투명한 프리즘은 새 검색에서 배경이나 다른 면을 잡을 수 있으므로 두 동작을 분리했다.

## 사용 방법

1. 앱의 자동 상태에서 폰과 프리즘 사이 거리를 맞추고, 프리즘이 선명하게 보이도록 한다.
2. **현재 초점 고정**을 누르고 잠깐 멈춘다. **초점 잠금 확인됨 / 촬영 조건 고정됨**을 기다린다.
3. 같은 거리를 유지하며 프리즘을 돌려 검사한다. 잠금에는 자동 해제 타이머를 사용하지 않는다.
4. 다시 초점을 찾고 싶으면 프리즘 모서리나 결함처럼 경계가 보이는 부분을 검사 영역 중앙에 놓고 **초점 다시 맞춤**을 누른다. 화면을 누르면 영역 중심을 옮길 수 있다.
5. 검색에 실패하면 고정 완료로 표시하지 않고 자동 상태로 돌아간다. 거리를 조금 늘리거나 모서리를 조준해 다시 시도한다. 자동 상태에서 선명하게 보이면 **현재 초점 고정**을 사용할 수 있다.

검색·실패·렌즈 이동 중에는 검사 시작을 허용하지 않는다. 잠금 중 **취소**를 누를 수 있고, **자동**으로 돌아가면 잠금을 푼다. 화질·카메라 화면 크기·배율을 바꾸면 기존 잠금을 재사용하지 않고 다시 맞추도록 한다. 카메라가 잠금을 잃으면 검사 시작이 대기 상태가 된다.

프리뷰가 준비되기 전에는 고정 버튼을 활성화하지 않는다. 실패 이유는 고정 버튼 아래에 표시한다. 연속 자동초점을 지원하지 않는 기기는 영역 초점 검색·잠금으로 대체한다. 최소 초점 거리가 명시적으로 0 D인 고정초점 렌즈는 AF OFF 상태를 확인하고 **고정 초점 렌즈 확인됨**을 표시한다. 최소 거리 정보가 없다는 이유만으로 고정초점 렌즈로 취급하지 않는다.

수동 초점은 설정의 슬라이더를 직접 조작할 때만 적용한다. 기기에 따라 거리 단위의 정확성이 달라 D(diopter)로 표시하며, 숫자를 실제 피사체 거리로 단정하지 않는다. 고정초점 카메라에는 지원하지 않는 수동 조절을 제공하지 않는다.

초점 거리 보고가 없어도 성공한 하드웨어 잠금은 사용할 수 있다. 다만 다른 잠금 세션의 초점이 같다고 확인할 수 없으므로 이전 검사 기준을 재사용하지 않는다. 무한대를 뜻하는 실제 0 D 값과 보고 없음은 구분한다. 자동초점 잠금·수동 초점 방식이 바뀐 기존 기준도 새 조건에서 다시 등록해야 한다. 사진과 기존 기록은 보존한다.

샤프닝·노이즈 처리 요청은 자동 상태와 고정 상태에서 같게 유지한다. 저장 사진과 실시간 판정 모두 이 카메라 스트림을 사용하며, 컬러 PNG 저장과 HD/FHD/QHD/4K 화질 선택을 유지한다.

## 검증 범위

단위 테스트는 현재 초점 유지와 새 검색의 모드 구분, 성공·실패·검색·렌즈 이동 상태, 미보고·무한대 초점 거리, 수동 초점의 실제 적용, 초점 방식별 기준 분리를 확인한다. Android 실행 테스트는 실제 CameraX 스트림에서 현재 초점 잠금, 5초 이후 유지, 해제·재고정, 화질 변경 후 재고정, 새 검색의 실제 성공 또는 실패 안내와 복구를 확인한다. 컬러·4K 저장 및 기존 기록 검증도 유지한다. 가상 카메라 테스트는 실제 폰 렌즈의 선명도를 측정하지 않는다.
