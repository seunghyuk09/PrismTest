# v26 최종 결과의 후보 표시

새 검사에서 자동 저장하는 표시 사진과 결과 화면의 **의심 위치 표시**에 다음 규칙을 적용한다. 원과 번호를 같은 색으로 표시한다.

| 후보 번호 | 색 |
|---|---|
| 1–3 | 빨강 |
| 4–6 | 주황 |
| 7–10 | 노랑 |
| 11 이후 | 표시하지 않음 |

번호는 기존 후보 점수순이다. 색은 순번을 구분하며 후보의 불량 확정을 뜻하지 않는다. 사진에는 최대 10곳을 표시하고, 검사 점수 계산과 JSON 기록의 전체 후보 좌표는 유지한다.

결과 화면과 자동 저장된 표시 PNG 모두에 적용한다. 원본 컬러 사진은 원본으로 보존한다. 이전 버전에서 이미 저장한 사진은 당시 표시와 안내를 유지한다. 실시간 화면과 검증기의 표시는 이번 변경 대상에 포함하지 않는다.

사진 표시를 바꾼 업데이트이므로 기존 검사 기준을 다시 등록할 필요가 없다. v25의 초점 고정과 HD/FHD/QHD/4K 화질 선택을 유지한다.

기존 단위 테스트 68개와 Android 실행 시험 10개가 통과했다. [검증 기록](https://github.com/seunghyuk09/PrismTest/actions/runs/45736698242)과 같은 APK 바이트를 배포한다.
