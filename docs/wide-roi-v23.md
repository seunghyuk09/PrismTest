# v23 검사 영역 확대

노란 검사 영역의 기본 한 변을 화면 영상 짧은 변의 **45%에서 65%**로 넓혔다. 가로·세로가 각각 약 44% 커진다. 촬영 거리와 화면 표시 방식에 따라 실제 길이가 달라지므로, 실물의 가로·세로를 정확히 10mm씩 확장했다는 뜻은 아니다.

- 화면에 현재 크기를 **검사 영역 65%**로 표시한다.
- **+ / −**로 가로·세로를 함께 조절한다. 선택한 크기는 앱을 다시 열어도 유지한다.
- 자동 추적은 중심을 따라가고 사용자가 정한 크기를 유지한다. 자동 추적으로 영역이 다시 작아지지 않는다.
- 검사·결과 저장 중에는 크기 변경을 막는다.
- 분석과 자동 저장 표시에는 동일한 ROI 좌표를 사용한다.

## 판정 기준

검사 영역을 넓히면 점수에 포함되는 배경과 반사도 바뀐다. v23은 영역 크기와 자동 추적 설정을 촬영 조건 프로필에 포함한다. 다른 크기의 기준이나 이전 v22 프로필로 바로 합격시키지 않는다.

기존 사진·기록과 등록 데이터를 자동으로 삭제하지 않는다. 새 영역에서 기준을 등록하려면 설정에서 해당 유형의 이전 기준을 초기화한 뒤 양품·확인된 불량 샘플을 다시 등록한다. 기준이 맞지 않으면 **기준 없음**을 유지한다.

정밀 화질과 사진 확대는 [v22 사용법](image-quality-v22.md), 자동 저장은 [v21 사용법](auto-result-v21.md)을 참고한다.

## 검증

릴리스 빌드와 단위 테스트 **51개**가 통과했다. 영역 크기·자동 추적 설정이 바뀌면 이전 판정 기준과 구분되는지 검증한다.

추가한 GitHub Actions의 **Validate published Android APK**는 README의 APK 자체를 설치하고 설치된 파일의 SHA-256을 비교한다. 새로 빌드한 다른 앱으로 배포 파일 검증을 대체하지 않는다. Android 11 x86_64에서 저장 관련 4개 테스트와 카메라·검사 영역 조절 관련 1개 테스트를 실행하고 로그·보고서·결과 화면을 보관한다.

**2026-11-26(한국 시간), Android 실행 테스트 5개가 모두 통과했다.** [실행 기록](https://github.com/seunghyuk09/PrismTest/actions/runs/45716424088)의 공지에 검증한 APK SHA-256과 통과 개수가 남아 있다.

1. 촬영 프레임이 없으면 재검 기록을 저장한다.
2. 제공된 디그 예시의 원본·표시 사진과 JSON을 저장하고 화소·후보 좌표를 확인한 뒤, 카메라 권한 없이 결과 화면을 연다.
3. 2560×1920 원본을 90도 회전해 1920×2560으로 저장하고 지정한 화소 값을 보존한다.
4. 기록 생성 실패 시 부분 저장 파일을 정리한다.
5. 검사 영역 65% → 70% → 65% 조절과 설정 저장, 표준/정밀 전환, 카메라 화면 확대에 따른 공통 크롭 재연결을 확인한다.

KVM을 사용한 Android 11 x86_64 가상기기에서 **README에 올린 파일 자체**를 검증했다. SDK 준비·가상기기 경로 문제를 해결한 후 완료한 결과이며, 초기 실패를 통과로 세지 않는다. [빌드 정보](../downloads/PrismScope-v23-build-info.json)에 같은 실행 기록을 연결한다. 실제 폰의 광학 해상도·프레임률·결함 검출 정확도는 별도 현장 검증이 필요하다.
