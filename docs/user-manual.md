# PrismScope 사용설명서

프리즘을 카메라로 비추면 **양품 / 재검 / 불량**을 화면에 띄우는 앱입니다.

---

## 1. 설치

**https://github.com/seunghyuk09/PrismTest/releases/latest** 에서
`PrismScope-bN.apk` 를 눌러 설치합니다.

설치가 막히면:
1. **설정 → 보안 및 개인정보 보호 → 자동 차단 → 끄기**
2. "이 출처의 앱 설치 허용"이 뜨면 브라우저를 허용
3. 그래도 막히면 Play 스토어 → 프로필 → Play 프로텍트 → 톱니 → "기기 유해 앱 검사" 끄기

설치 후 자동 차단은 다시 켜도 됩니다.

## 3. 처음 한 번만 하는 설정

### ① 프리즘을 지그에 놓고 조명을 켠다

### ② 검사 영역을 프리즘에 맞춘다
화면에서 프리즘이 있는 곳을 **손가락으로 누르면** 노란 사각형이 그리로 옮겨집니다.
「영역 크게 / 작게」로 프리즘을 덮도록 크기를 맞춥니다.

> 사각형이 프리즘 **밖까지** 덮으면 배경이 섞여 지수가 틀어집니다.
> 프리즘 안쪽으로 조금 작게 잡는 편이 낫습니다.

### ③ 「현재 상태로 고정」을 누른다
앱은 처음에 자동 노출로 시작합니다. 화면이 잘 보이는 상태가 되면 이 버튼을 누르세요.
**그 순간의 밝기·초점·색이 잠깁니다.**

이게 중요한 이유: 자동 노출이 살아 있으면 프리즘을 바꿀 때마다 카메라가 밝기를
알아서 바꿔버려서, 얼룩이 심한 개체도 "적당히 밝게" 보정되어 버립니다.
**고정하지 않으면 비교가 성립하지 않습니다.**

### ④ 양품을 등록한다 — 기준 만들기
**설정** → 양품이 확실한 프리즘을 하나씩 올리면서 **「양품으로 등록」**을 누릅니다.

- **최소 5개**, 많을수록 정확합니다 (10~20개 권장)
- 앱이 양품들의 얼룩 지수 분포에서 합격 기준을 자동 계산합니다

> 임계값을 제가 임의로 정하지 않는 이유: 조명·거리·기기가 다르면 숫자도 달라집니다.
> **여러분 공정에서 실제로 나온 값**에서 뽑아야 맞습니다.

## 4. 매일 하는 검사

1. 프리즘을 지그에 올린다
2. 화면의 판정을 읽는다

| 표시 | 뜻 | 조치 |
|---|---|---|
| 🟢 **양품** | 얼룩 지수가 합격 기준 미만 | 통과 |
| 🟡 **재검** | 애매한 구간 | **사람이 직접 확인** |
| 🔴 **불량** | 기준을 크게 벗어남 | 불량 처리 |
| ⚪ 기준 미설정 | 양품 등록이 5개 미만 | 설정에서 등록 |

3. 기록이 필요하면 **「측정 저장」** — 사진과 수치가 함께 저장됩니다

## 5. 얼룩 지수가 뭔가

```
얼룩 지수 = 검사 영역에서 가장 밝은 부분(상위 1%) − 정상면 밝기(중앙값)
```

암시야 조명에서 **정상면은 어둡고, 얼룩은 빛을 산란시켜 밝게 뜹니다.**
그 밝기 차이가 곧 얼룩의 세기입니다. 0~255 범위이며 클수록 심합니다.

- 깨끗한 프리즘 → 전체가 고르게 어두움 → 지수 **작음**
- 얼룩 있는 프리즘 → 일부만 밝게 뜸 → 지수 **큼**

사람이 어디를 봐야 할지 지정할 필요가 없습니다. **영역 안에서 가장 밝은 곳을
앱이 알아서 찾습니다.**

## 6. 경고 문구

| 문구 | 원인 | 조치 |
|---|---|---|
| 화면이 너무 어둡습니다 | 조명 꺼짐 / 노출 부족 | 조명을 켜거나 「자동」으로 되돌린 뒤 다시 고정 |
| 너무 밝아 하얗게 뭉개집니다 | 빛이 정면으로 들어옴 | 조명 각도를 더 비스듬히 |
| 초점이 흐립니다 | 거리가 안 맞음 | 프리즘까지 거리 조정 (최소 10 cm 이상) |

경고가 뜬 상태의 측정값은 믿지 마십시오.

## 9. 자주 묻는 것

**Q. 기준을 다시 만들고 싶습니다**
설정 → 「초기화」 → 양품을 다시 등록합니다.
**조명이나 거리를 바꿨으면 반드시 다시 만들어야 합니다.** 지수가 달라집니다.

**Q. 조명을 바꾸면 어떻게 되나요**
얼룩 지수가 통째로 달라집니다. 「현재 상태로 고정」을 다시 누르고,
양품 기준도 초기화 후 재등록하십시오.

**Q. 다른 폰에서도 되나요**
동작은 합니다. 다만 **기기마다 센서가 달라 지수가 다르게 나오므로,
그 폰에서 양품 기준을 새로 등록**해야 합니다.

**Q. 인터넷이 없어도 되나요**
됩니다. 이 앱은 **네트워크 권한 자체가 없습니다.** 촬영한 사진이 밖으로
나갈 경로가 존재하지 않습니다.

**Q. 재검이 너무 많이 나옵니다**
양품 등록 개수가 적으면 기준이 좁게 잡힙니다. 양품을 더 등록해 보십시오.
그래도 많으면 조명 조건이 불안정한 것이므로 지그를 점검해야 합니다.

## 10. 현재 한계 — 알고 쓰셔야 할 것

- **위치를 구분하지 않습니다.** 얼룩이 S3 전반사면에 있는지, 광로 밖 내부에 있는지
  가리지 못합니다. 지금은 밝기 하나로만 봅니다 (`docs/gas-defect.md` 참조)
- **한 면씩만 봅니다.** S1 과 S3 를 모두 검사하려면 프리즘을 돌려 두 번 재야 합니다
- **버(Burr)는 못 잡습니다.** 촉각 검사 항목이라 카메라로 대체 불가입니다
- **판정 기준은 여러분이 등록한 양품에서 나옵니다.** 등록한 양품 중에 불량이
  섞여 있으면 기준이 느슨해집니다. 등록할 개체는 확실한 것만 쓰십시오
