# PrismScope 사용설명서

암실에 폰을 고정하고, **프리즘은 손에 들고 돌려가며** 검사합니다.
육안검사에서 하던 동작 그대로이고, 앱은 그동안 본 것을 수치로 남깁니다.

---

## 1. 설치

**https://github.com/seunghyuk09/PrismTest/releases/latest** 에서
`PrismScope-bN.apk` 를 눌러 설치합니다.

설치가 막히면:
1. **설정 → 보안 및 개인정보 보호 → 자동 차단 → 끄기**
2. "이 출처의 앱 설치 허용"이 뜨면 브라우저를 허용
3. 그래도 막히면 Play 스토어 → 프로필 → Play 프로텍트 → 톱니 → "기기 유해 앱 검사" 끄기

설치 후 자동 차단은 다시 켜도 됩니다.

## 3. 화면 구성

```

│    │  프리즘    │        │     화면을 누르면 이동, 오른쪽 아래 −/+ 로 크기
│    └───────────┘        │
├─────────────────────────┤
│ 촬영 조건 고정됨  [자동]   │

│ └─────────────────────┘ │
│ ● 양품                   │  ← 종합 판정

│ ● 검정 이물   2.0 [양품][불량]│
│ [측정 저장] [설정] [도움말]  │
└─────────────────────────┘
```

## 4. 검사하는 법

### ① 폰을 암실에 고정하고 조명을 켠다

### ② 프리즘을 노란 사각형 안에 넣는다
화면을 손가락으로 누르면 사각형이 그리로 옮겨집니다.
오른쪽 아래 **− / +** 로 크기를 맞춥니다.

> 사각형이 프리즘 **밖까지** 덮으면 배경이 섞여 점수가 틀어집니다.
> 손으로 돌릴 때 프리즘이 밖으로 나가지 않을 만큼은 넉넉하게 잡으세요.

### ③ 「현재 상태로 고정」을 누른다
앱은 자동 노출로 시작합니다. 화면이 잘 보이면 이 버튼을 누르세요.
**그 순간의 밝기·초점·색이 잠깁니다.**

고정하지 않으면 프리즘을 바꿀 때마다 카메라가 밝기를 알아서 바꿔버려
얼룩이 심한 개체도 "적당히 밝게" 보정됩니다. **고정 없이는 비교가 성립하지 않습니다.**

### ④ 「검사 시작」을 누르고 8초 동안 천천히 돌린다
화면 위에 남은 초가 뜹니다. 그동안 프리즘을 이리저리 기울이고 돌리세요.
앱은 그 8초 동안의 **유형별 최고 점수**로 판정합니다.

> **왜 돌리는가** — 결함은 각도가 맞을 때만 빛납니다. 스크래치가 특히 심해서
> 한 각도로 고정해 찍으면 그냥 놓칩니다. 검사원이 손으로 기울여 보는 것과 같은 이유입니다.

### ⑤ 결과를 읽는다
유형별로 점수와 색이 뜨고, 맨 위에 종합 판정(가장 나쁜 유형 기준)이 나옵니다.

## 5. 기준 만들기 — 샘플 등록

처음에는 모든 유형이 **「기준 없음」** 입니다. 앱이 임계값을 지어내지 않기 때문입니다.
조명·거리·기기가 바뀌면 숫자가 통째로 달라지므로,
**여러분 공정에서 실제로 나온 값**에서 뽑는 것 말고는 방법이 없습니다.

### 등록 방법
1. 상태를 아는 개체(양품이 확실하거나, 어떤 불량인지 아는 것)를 놓고
2. **「검사 시작」** 으로 8초 검사를 한 다음
3. 해당 유형 줄의 **「양품」** 또는 **「불량」** 을 누릅니다

> 등록 버튼은 **검사가 끝나야** 활성화됩니다. 방금 잰 값을 등록하는 구조입니다.

### 몇 개나
| 상태 | 필요 |
|---|---|
| 양품 | **5개 이상** — 이때부터 판정 시작 |
| 불량 | **3개 이상** (유형별) — 이때부터 경계가 두 분포 사이로 이동 |

**불량 샘플이 왜 필요한가** — 양품만 알면 "정상에서 얼마나 벗어났나"밖에 못 봅니다.
불량이 실제로 어디쯤 나오는지 알아야 경계를 그 사이에 놓을 수 있고,
그래야 과검이 줄어듭니다. **과검 1건 = 폐기 1건**이므로 이게 곧 돈입니다.

### 유형별로 따로 등록합니다
스크래치 불량품이라도 표면 얼룩이 없다면, 그 개체는
**「표면 얼룩」줄에서는 「양품」, 「스크래치」줄에서는 「불량」** 으로 등록하는 게 맞습니다.
한 개체가 여러 줄에 기여합니다.

## 6. 상태 표시의 뜻

| 표시 | 뜻 | 조치 |
|---|---|---|
| **양품 샘플 부족** | 양품 5개 미만 | 양품을 더 등록 |
| **불량 샘플 없음** | 양품만으로 판정 중 (평균+3σ / +6σ) | 불량 샘플 3개 등록하면 정확해짐 |
| **구분 양호** | 양품·불량이 확실히 갈림 | 그대로 쓰면 됨 |
| **양품·불량이 겹침** | 두 분포가 겹쳐 못 가름 | 아래 참조 |

**「겹침」이 뜨면** — 샘플을 더 넣어보고, 그래도 안 갈리면 **알고리즘이 아니라 조명 문제**입니다.
그 유형은 지금 조명에서 보이지 않는다는 뜻입니다.
특히 **검정 이물**은 암시야(어두운 배경)에서 원래 잘 안 보입니다. 검은 것을 검은 배경에서 보는 셈이라
투과광(뒤에서 비추기)이 있어야 합니다.

## 7. 판정 색

| 색 | 뜻 | 조치 |
|---|---|---|
| 🟢 **양품** | 합격 경계 미만 | 통과 |
| 🟡 **재검** | 애매한 구간 | **사람이 직접 확인** |
| 🔴 **불량** | 불량 경계 이상 | 불량 처리 |
| ⚪ **기준 없음** | 샘플 부족 | 등록 |

초기에는 재검이 많이 뜨는 게 정상입니다. **미검(불량을 흘림)이 과검보다 훨씬 비싸서**
일부러 재검 구간을 넓게 잡아뒀습니다. 데이터가 쌓이면 좁아집니다.

## 8. 유형별 점수가 어떻게 나오는가

네 유형 모두 암시야에서 밝게 뜨거나 어둡게 막습니다. 다른 것은 **모양**입니다.

| 유형 | 모양 | 점수 |
|---|---|---|
| 표면 얼룩 | 넓게 퍼짐 | 대비 × (1 − 선형성) × 넓이 |
| 흰색 이물 | 작고 아주 밝음 | 점세기 × (1 − 선형성) |
| 스크래치 | 가늘고 긴 선 | 대비 × 선형성 |
| 검정 이물 | 빛을 막음 | 아래쪽 대비 |

곱셈인 게 핵심입니다. 밝기만 보면 세 유형이 뒤섞이고, 모양만 보면 흐릿한 자국까지 걸립니다.
**밝으면서 동시에 그 모양일 때만** 점수가 오릅니다.

- **대비** = 상위 1% 밝기 − 중앙값
- **선형성** = 밝은 화소 분포의 장축/단축 비 (0=원형, 1=선)
- **점세기** = 최대 밝기 − 상위 1% (작은 알갱이는 최대값만 올림)
- **넓이** = 밝은 화소가 검사 영역에서 차지하는 비율

## 9. 경고 문구

| 문구 | 원인 | 조치 |
|---|---|---|
| 화면이 너무 어둡습니다 | 조명 꺼짐 / 노출 부족 | 조명을 켜거나 「자동」으로 되돌린 뒤 다시 고정 |
| 너무 밝아 하얗게 뭉개집니다 | 빛이 정면으로 들어옴 | 조명 각도를 더 비스듬히 |
| 각도 변화 부족 — 다시 | 8초 동안 거의 안 움직임 | 더 크게 돌려서 다시 검사 |

**「각도 변화 부족」이 뜬 검사는 "결함 없음"의 근거가 되지 못합니다.**
돌리지 않았으면 각도가 맞는 순간이 없었을 뿐입니다. 다시 하세요.

## 12. 자주 묻는 것

**Q. 기준을 다시 만들고 싶습니다**
설정 → 「전체 초기화」 → 다시 등록합니다.
**조명이나 거리를 바꿨으면 반드시 다시 만들어야 합니다.**

**Q. 다른 폰에서도 되나요**
동작은 합니다. 다만 기기마다 센서가 달라 점수가 다르게 나오므로
**그 폰에서 샘플을 새로 등록**해야 합니다.

**Q. 인터넷이 없어도 되나요**
됩니다. 이 앱은 **네트워크 권한 자체가 없습니다.**

**Q. 손으로 돌리면 사람마다 다르지 않나요**

## 13. 현재 한계 — 알고 쓰셔야 할 것

- **손 동작이라 재현성이 떨어집니다.** 돌리는 속도·범위가 사람마다 달라
  같은 개체도 값이 흔들립니다. 같은 개체를 3번 재서 편차를 먼저 확인하십시오.
  편차가 크면 회전 안착부(턴테이블)를 지그에 넣는 것이 다음 수순입니다.
- **검정 이물은 암시야에서 잘 안 보입니다.** 투과광 조명을 추가해야 제대로 잡힙니다.
- **위치를 구분하지 않습니다.** 얼룩이 S3 전반사면에 있는지 광로 밖 내부에 있는지
  가리지 못합니다 (`docs/gas-defect.md`)
- **한 면씩만 봅니다.** S1 과 S3 를 모두 보려면 두 번 검사해야 합니다
- **버(Burr)는 못 잡습니다.** 촉각 검사 항목입니다
- **등록한 샘플이 곧 기준입니다.** 양품으로 등록한 것 중에 불량이 섞이면
  기준이 느슨해집니다. 확실한 것만 등록하십시오
